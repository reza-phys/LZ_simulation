# P037: Which electroweak multiplets can be inelastic dark matter with a 100–400 keV neutral splitting?
- Simulated arXiv date: 2026-09-09
- Primary arXiv category: hep-ph
- Author profile: electroweak dark-matter model builders
- Category (from your taxonomy): MODEL

**Abstract.** Every SU(2)_L fermion multiplet with hypercharge Y ≠ 0 has a neutral Dirac component with Z vector coupling −(g/c_W)Y, so it scatters in LZ like P007's Higgsino with σ_n = 7.4×10⁻³⁹(2Y)² cm². Splitting it into two Majorana states needs an operator χχ(H†)^{4Y}/Λ^{4Y−1}. One LZ event requires δ = 366, 374, 379, 383 keV (Y = ½, 1, 3/2, 2; 1 TeV), all inside P021's 360–385 keV band, with Λ = 1.7×10⁵ TeV, 22 TeV, 3.6 TeV, 1.7 TeV.

**Question and approach.** Which (n, Y) multiplets can be the LZ scatterer, how is δ generated, what scale gives 100–400 keV, and how does the required δ move with the larger Z coupling? We enumerate n = 2–5 multiplets with a neutral component (T₃ = −Y); since c_p/c_n is Y-independent the spectrum shape equals P007's, so we scale P007's WimPyDD event grid (annual Baxter halo, LZ efficiency, 2.84 t·yr) by (2Y)² (verified live at four points, ratio 1.0000), invert N(δ) for N = 3.65/1/0.105 (90 % one-event band), solve δ = v^{4Y}/Λ^{4Y−1} for Λ (v = 246 GeV), cross-check against P007's gaugino masses, and evaluate one-loop charged–neutral splittings with P014's method.

**Results.** Y = 0 multiplets have no Z coupling (P014). Unsplit Y ≠ 0 states exceed LZ's 2024 SI limit by 5×10⁷(2Y)² and the Fig. 6 inelastic edges by ×299(2Y)² (300 keV) and ×3.5(2Y)² (350 keV), so each survives only in the window [δ(N=3.65), δ_max = 387 keV]; since N falls ×5 per 10 keV there, (2Y)² = 4, 9, 16 shifts δ by only +8, +13, +17 keV (1 TeV):

At 2 TeV δ(N=1) = 375–395 keV (δ_max 402). The doublet's Λ = v²/δ equals 4M₁/g′² for P007's bino masses to 1 %. Y = 1 needs a 21–33 TeV mediator (Λ > M_DM). For Y = 3/2 and 2, Λ ≈ 3.6 and 1.7 TeV is at or below the recalled thermal masses, while Λ ≥ 10 TeV would give δ = 2 keV and 1 eV — effectively elastic, excluded. Δm(Q=1) = 342, 511, 680, 850 MeV; the (4, ½) and (5, 1) multiplets have a Q = −1 state lighter than the neutral one (for M > 1.36 TeV; by 166–193 MeV) and need a tree-level lift.

**Caveats.** Thermal masses other than the doublet's 1.1 TeV are recalled and uncertain (±30 %), so δ(N=1) is given at 1, 2, 4 TeV; the halo tail shifts δ(N=1) by −3/+10 keV (v_esc 528/560), Sun-frame/June by +3/+7 keV; the operator coefficient is O(1) (⟨H⟩ = v/√2 lowers Λ by ×0.5–0.67); one-loop splittings carry a 7 % scheme spread; cτ values are scaling estimates.

**Conclusion.** The LZ event does not single out the Higgsino: any Y ≠ 0 multiplet fits with δ = 366–383 keV at 1 TeV. Only the doublet (Λ ≈ 1.7×10⁵ TeV, PeV gauginos) and the Y = 1 triplet (22 TeV mediator) get δ from a consistent heavy-mediator EFT.
