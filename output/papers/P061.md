# P061: Prior sensitivity of the dark-matter posterior: how robust is any probability statement about the LZ event?
- Simulated arXiv date: 2026-09-12
- Primary arXiv category: physics.data-an (cross-list hep-ph)
- Author profile: Bayesian epistemology-minded physicists

- Builds on / responds to: LZ arXiv:2609.02823; dossier Section 5; P001, P008, P016, P027, P045; background eliminations P004, P010, P013, P019, P022, P029, P033, P036, P040, P041, P049; P020, P035

**Abstract.** We propagate the corpus's eliminations of specific backgrounds and P027's model-marginalised Bayes factor (B_DM = 16–29) through P001's three-hypothesis posterior, scanning five judgemental hyper-parameters. Under a log-uniform "community prior", P(DM | event) has median 0.015 and 68 % range 0.002–0.14; it exceeds 0.5 in 2.4 % of the hyper-prior volume and stays below 0.1 in 80 %. The prior π_DM carries 56 % of the variance. A second-detector reanalysis is the most informative next measurement.

**Question and approach.** How much of any P(DM) statement is data and how much prior? We write P(DM) = π_DM L_DM / (π_DM L_DM + π_B b + π_U L_U), L_DM = (B_DM/f_FP) b, with b = 5.7 × 10⁻⁴ (P016), B_DM ∈ [6.6, 45] (P027), a forking-paths divisor f_FP ∈ [1, 10] for the non-blind FV shrink and salting failure, π_U ∈ [0.01, 0.5], π_DM ∈ [10⁻³, 0.3]. L_U = L_acc + L_rest: L_acc = 9.3 × 10⁻³ sums the corpus residuals (artefacts 0.006, ER 2.8 × 10⁻³, accidentals, activation and atmospheric ν ~10⁻⁴ each, neutrons and wall MSSI ≤ 10⁻⁵; upper bracket 0.066); L_rest ∈ [10⁻³, 0.3] is unaccounted. We reproduce P001's 0.46/0.09 to 1 %.

**Results.** *Map (Fig. 1).* At central values (π_U = 0.1, f_FP = 3, B_DM = 16.4), P(DM) = 0.1 needs π_DM ≥ 0.085 (L_rest = 0.01) and P(DM) = 0.5 needs π_DM ≥ 0.66 — unreachable; only the optimistic corner (f_FP = 1, B_DM = 28.7, π_U = 0.05) allows P > 0.5, for π_DM ≥ 0.089. Odds ∝ π_DM^1.0 π_U^−0.77 L_rest^−0.41 (B_DM/f_FP)^1.

*Community prior (Fig. 2).* Median 0.015, 68 % 0.0016–0.137, 95 % 0.0002–0.50; fractions P > 0.5 / 0.1–0.5 / < 0.1 = 2.4/17.8/79.7 %. Variance shares of logit P: π_DM 0.56, π_U 0.14, L_rest 0.14, f_FP 0.09, B_DM 0.06. π_DM = 0.2 (dossier) gives 0.17 (0.04–0.46); f_FP = 1 gives 0.047 (0.005–0.32).

*Reference class* (B_typ = 14.6, SBB cap): base rate r = 0.05/0.2 gives P = 0.019/0.086, i.e. π_DM = 0.015/0.072.

*Dossier table* (dossier weight × corpus likelihood, normalised): DM 0.20 → 0.16 (0.02–0.29); artefact + unknowns 0.18 → 0.73; ER 0.13 → 0.09; wall MSSI, neutrons → 10⁻⁴; accidentals, activation → 0.002; modelled fluctuation → 0.014.

*Value of information* (Fig. 3; prior entropy 0.171 nats). XENONnT + PandaX 270 keV reanalysis 0.027–0.074 nats (16–43 %); LZ's 6.76 t·yr 0.008 nats if the unknown is a steady rate (which predicts new events as DM does) but 0.052 if one-off; artefact audit 0.011; wall-MSSI calibration 0.

**Caveats.** Summing channel residuals gives each the whole π_U (conservative against DM by ≤ ×1.55). Channel likelihoods are corpus central values; the 95 %-allowed bracket (accidentals k < 183) raises L_acc to 0.066 and halves the median. The base rate awaits P083. H_U predictives (one-off vs steady, LZ-specific vs generic: f_trans = 0.5, f_spec = 0.7) are judgements. The dossier weights already used the event, so the table update partly double-counts.

**Conclusion.** No probability statement about the event is robust to the prior: P(DM) spans 0.002–0.14 (68 %) across defensible priors and exceeds 0.5 only for π_DM ≳ 0.1 with no forking-paths penalty and π_U ≲ 0.05. Only a second detector separates DM from an LZ-specific unknown.
