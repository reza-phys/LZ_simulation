# P031: Relativistic operator matching for the LZ-preferred nonrelativistic operators with directdm
- Simulated arXiv date: 2026-09-09
- Primary arXiv category: hep-ph
- Author profile: DM effective-field-theory practitioners
- Category (from your taxonomy): EFT
- Builds on / responds to: LZ paper (arXiv:2609.02823, Theory paragraph, Table S6, LEE supplement); P003, P012, P016, P027

**Abstract.** We match 29 single relativistic DM–quark/gluon/photon operator structures (dimension 5–7) onto the Anand NR basis with directdm 2.2.2 and compute LZ spectra with WimPyDD. Only pseudoscalar–pseudoscalar and pseudoscalar–GG̃ (→O6), scalar–pseudoscalar and scalar–GG̃ (→O10), and DM-dipole × quark axial/charge-weighted vector currents (→O9, O14, L10-like) reproduce a lone 248 keV event; they need Λ = 1.5–62 GeV ≪ m_χ. Anapole, tensor–tensor, axial–axial and photon dipoles predict 27–420 low-energy companions.

**Question and approach.** Which relativistic operators reduce to P003's compatible NR set (O6, O10, O9, O14, O5^v, L10-like), at what Wilson coefficient at μ = 2 GeV, and which are excluded by O1/O4/O7/O8/O11 dominance? For each structure (dipoles; V/A quark currents including anapole and Z-like isospin; gluon operators; m_q-weighted S/P/T; derivative dipole-type Q15–Q18; twist-2) directdm gives c_i^{p,n}(q) with pion/η and 1/q² poles; each q-structure enters WimPyDD separately (c⁰ = c_p + c_n). N_lo = R(5.4–55)/R(200–270 keV) with P003's efficiency classifies (≤5 compatible, >20 excluded); N_ROI(C) = C²N₁ = 1 event fixes Λ = C^{−1/(d−4)}; P016's Z(N_lo) curve is compared with Table S6.

**Results.** At 1000 GeV (Fig. 1; other masses in details.md):

| structure → NR operator | N_lo | Λ [GeV] |
|---|---|---|
| P–P (m_q χ̄iγ₅χ q̄iγ₅q) → O6 | 0.069 | 1.51 [1.30–1.84] |
| P–GG̃ → O6; S–GG̃ → O10 | 0.082; 0.47 | 1.69; 37 |
| S–P (m_q χ̄χ q̄iγ₅q) → O10 | 0.85 | 33 |
| χ̄σ^{μν}χ ∂_ν(q̄γ_μγ₅q) → O9 | 2.06 | 62 [54–76] |
| χ̄σ^{μν}iγ₅χ ∂_ν(q̄γ_μγ₅q) → O14 | 2.34 | 5.6 |
| χ̄σ^{μν}χ ∂_ν(ΣQ_q q̄γ_μq) → q²O4 + O6 | 2.52 | 49 |
| anapole → O8^p + O9 | 26.9 | 605 |
| A–A, T–T, V–A → O4, O4, O7 | 28–32 | 2100, 24, 44 |
| photon dipole; S–S, V–V → O1 | 422; 2760 | μ_χ = 9.3×10⁻⁷ μ_N; 630, 86 000 |

*Pion pole.* LZ's L2, L4 are nucleon-level contact O10, O6; quark-level isovector pseudoscalar currents give O10/(m_π²+q²), raising N_lo from 3.1 to 25.8 (L2^v: 3.1σ → predicted 2.7σ); universal couplings cancel π against η at low q. Z-like A–A acquires c₆ = 29 GeV⁻² (c₄ = −2.6) at q = 245 MeV, yet N_lo rises 28→56.

*Table S6.* Certain/likely identifications (L1, L3, L4, L5, L7, L15) match to rms 0.25σ (Fig. 3); the anapole predicts 2.7σ, so L16 (3.4σ) is not the anapole; pure O9 (3.4σ) matches L11≡L14.

*Running.* Tensor coefficients run 1→0.573 (M_Z→2 GeV); no class changes. L10 reproduces P012 (3.334 vs 3.336 events); photon-dipole μ_χ(1 event) = 9.29×10⁻⁷ μ_N (P012 9.16×10⁻⁷).

**Caveats.** Tree-level, single-operator matching with q = 0 form factors apart from the explicit poles; P003 efficiency and thresholds; Z_pred uses P016's curve (0.2σ scatter, saturating at 3.6σ). Q15–Q18 structures and L6–L16 identifications are inferred (likely/uncertain). Majorana DM retains only the P–P, S–P and gluon routes.

**Conclusion.** No natural heavy-mediator contact operator explains the event: compatible structures need Λ = 1.5–62 GeV (Λ/m_χ ≤ 0.06), the O6 routes lie below the 2 GeV matching scale, while the natural Λ ≳ TeV currents (V–V, A–A) and the anapole are excluded.
